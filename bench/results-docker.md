# JWT decode benchmarks

Generated 2026-10-16 from `bench/results-docker/` by `bench/compare.py`, on AWS c9g.2xlarge, Graviton5 (aarch64), Linux.
Run in Docker, one container per library, each limited to 1 CPU (pinned) and 500 MB with no swap. Each case gets 1,000 untimed decodes, then 10,000 timed.

Each decode verifies an HS256 signature and checks `exp` and `aud`, as a real caller
would. Times are µs per decode: the mean over 10,000 decodes of the same token, after
1,000 untimed (lower is better); `(Nx)` is the speed-up vs pyjwt 2.15.1.
