# x86_64 cross-check

The same benchmarks as the [published ones](index.md), run on GitHub's x86_64 Linux runner, to
check the results hold on an Intel or AMD CPU. That runner gets different CPUs from run to run,
so the times here change between runs more than the ratios do; each part names the CPU it ran on.

In this run, on an AMD EPYC 9V74, the HS256 race finishes in the same order as on arm64: ryjwt
about 27 times faster than PyJWT into a `Struct`, and twice as fast as jsonwebtoken's struct. The
RS256 race doesn't: aws-lc (under ryjwt and jsonwebtoken) checks RSA signatures in half the time
it takes on arm64, and ryjwt finishes first, about 15% ahead of jsonwebtoken and fast-jwt.
