# x86_64 cross-check

The same benchmarks as the [published ones](index.md), run on GitHub's x86_64 Linux runner, to
check the results hold on an Intel or AMD CPU. That runner gets different CPUs from run to run,
so the times here change between runs more than the ratios do; each part names the CPU it ran on.

In this run, on an AMD EPYC 9V74, ryjwt finishes first in both races, as it does in the published
numbers on Graviton5. With HS256, it's about 27 times faster than PyJWT into a `Struct`, and twice
as fast as jsonwebtoken's struct; with RS256, it's about 15% ahead of jsonwebtoken and fast-jwt.
Further down, a few places swap: with HS256, jsonwebtoken's struct comes ahead of ryjwt's pydantic
model, and joserfc ahead of jose; with RS256, jsonwebtoken comes ahead of fast-jwt.
